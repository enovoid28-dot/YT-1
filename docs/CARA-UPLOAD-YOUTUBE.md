## Langkah upload (YouTube Studio)
1. Buka studio.youtube.com → **Buat** → **Upload video**.
2. Pilih file MP4 di atas. Karena rasionya 9:16 dan durasi < 3 menit, YouTube
   otomatis mengategorikan sebagai **Short** (centang "Also share to Shorts feed"
   bila muncul).
3. **Detail:**
   - Judul: `Ditarik ke Lubang Hitam: 33 Tempat Paling Gila di Tata Surya`
   - Deskripsi: salin dari dokumen di folder 03 (bagian DESKRIPSI)
   - Thumbnail: unggah `thumbnail_short-01...jpg`
4. **Audience:** Bukan "Made for kids". **Kategori:** Education.
   **Bahasa:** Indonesia.
5. **Tags:** salin 30 tag dari dokumen folder 03.
6. **Visibilitas:** Privat dulu → tonton sekali → baru Publik.
   Jam terbaik: 19.00–21.00 WIB.
7. **Setelah publik:**
   - Sematkan komentar: "Kamu paling takut nyangkut di planet mana? 👇"
   - Masukkan ke playlist "Perjalanan Tata Surya"
   - Tambah ke Shorts terkait: Short #2 saat sudah ada

- [x] Narasi Bahasa Indonesia, pria, jelas
- [x] Caption tiap tahap muat di frame, tidak terpotong
- [x] Thumbnail 1080×1920 dengan judul besar
